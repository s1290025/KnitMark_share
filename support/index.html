Knit Mark is a simple row and stitch counter for knitting and crochet.

How to use

  1. Create a project from the project list.
  2. Tap the large + buttons after you knit to count rows and stitches.
  3. When counting both rows and stitches, increasing the row saves the current row and stitch count to History and resets the stitch counter to 0.
  4. Use │→ to save the current count to History and start that counter again from 0.
  5. Use Undo to go back one action at a time.
  6. Use Save Progress to add a temporary “Paused” entry to History.
  7. Your counts, history, notes, and settings are saved automatically.
  8. Use the speaker button to turn the tap sound on or off.
  9. Open History to review saved counts, and use Notes for project details.
